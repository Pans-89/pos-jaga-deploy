# Product

## Purpose

An EasyPanel deployment exercise for an IT Ops practitioner. It demonstrates a web application, PostgreSQL, authenticated CRUD, health checks, and data persistence across restarts.

## Constraints

- Flask and PostgreSQL run as separate services.
- Target host has 2 GiB RAM and already runs monitoring and storage workloads.
- Keep resource use bounded and label all sample content as user-entered demonstration data.
- This is a learning/test app, not a production incident management system.

## Stack

User chose a moderately complex, resource-conscious stack: Flask + PostgreSQL.
